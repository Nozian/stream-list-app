# Entertainment Hub v1.3 — Netflix横送り収集版

旧版v1.3の機能（Prime Video自動縦スクロール収集、YouTubeグリッド・タグ・CSV/JSON、U-NEXT、作品検索・評価・視聴済み・メモ）を維持し、Netflixの新しい横並びマイリストに対応しました。

## Netflix「マイNetflix」の収集
1. Netflixにログインし、「マイNetflix」（マイリストの横並び行がある画面）を開く。
2. 右下のEntertainment Hubから **マイリストを横送り収集** をクリック。
3. まず左側へ戻って作品を収集し、続いて右へ自動で進んで新たに読み込まれた作品を収集します。
4. 途中で止めたくなったら画面右下の **収集を停止** をクリック。保存済み作品は消えません。
5. **ライブラリを開く** から収集した作品を縦一覧で検索、タグ付け、評価、CSV/JSON出力できます。

「マイリスト」という見出しがついた行を対象にし、ほかの「視聴中」「視聴済み」「おすすめ」の作品を混ぜない設計です。画面の見出しが検出できないときは対象行を推測して別の作品を収集することはせず、状況を表示します。

Netflixは2026年にMy List表示を横スクロール型へ変更しています。今回の収集はページ上のNext/Previousの矢印を優先し、通常のスクロール要素には補助的に対応します。ロード待ちを含むため大量の作品では時間がかかります。未読み込み分の全件保証はありません。Netflix APIから個人リストを直接取得する機能ではありません。

## 安全性
- 収集ボタン以外の作品の評価やマイリスト登録状態は変更しません。
- 収集済みのタグ・評価・メモを上書きしません。
- 旧拡張を削除する前にEntertainment HubのJSONをバックアップしてください。
- 複数ブラウザに展開する場合、拡張IDごとの保存領域は自動統合されません。

## v1.3 — Netflix横スクロール / YouTubeタイトル修正（2026-10-24）
- Netflixは**マイリストの行だけ**を検出し、その行の左右矢印（または行内の横スクロール可能領域）を動かします。**ページ全体の縦自動スクロールはしません**。対象行を検出できない場合は、横送りせず理由を表示します。
- 最初に左へ戻り、右端まで進めることを試みます。いつでも「収集停止」を押せます。未配信のカードなどは取得できない場合があります。
- YouTubeでは動画の表示タイトルを優先し、`title="True"` や `aria-label="true"` を作品名として採用しません。取得済みの「True」は、同じ動画を再収集したときに正しいタイトルで更新します。
- 既存の評価・タグ・メモ・視聴状態、検索、CSV/JSON、Prime Video収集を維持します。
- テスト：模擬Netflixページで4作品の横送り収集（ページの縦位置を維持）、模擬YouTubeで正しい日本語タイトル取得。**本物のサービスでの動作は未検証**です。

## v1.4 改善 (2026-10-24)
- Netflixのマイリスト見出し検出を、h2以外のspan/divの文字やARIAラベルまで拡大。行が見つからない場合は無理に別の行を集めず、「マイリスト行を指定」で対象を一度だけ選べます。Netflixの縦スクロール収集は行いません。
- 「新着作品のお知らせ」などの通知や、YouTubeの「再生済み」「True」を作品タイトルとして登録しません。作品ID/正式な動画タイトルが見つからないものは飛ばします。
- YouTubeグリッドはサムネイルへホバー、またはキーボードフォーカスで全文タイトルを表示します。ネイティブのタイトルヒントも付与。
- 保存済みの誤収集が残っている場合は、ライブラリの「誤収集を整理」を押すと、本人のメモ・タグ・評価がない明らかな誤収集だけ確認後に削除できます。自動削除はしません。
- 実サービスのログイン状態での動作は未検証です。


## v1.5 修正（2026-10-24）
- Netflixの `section[aria-labelledby]` と `data-uia="carousel-scroller"` の関係を認識する。
- マイリストの行をカードIDの有無と無関係に識別。ページ全体の縦スクロールはしない。
- ボタン名「再生」などをタイトルとして取り込まない。作品IDと実タイトルを確認できたものだけ登録。
- 取得不能なカードも診断件数（候補・ID・題名）を表示する。全件取得保証はない。
- 誤登録済み「再生」はJSONをバックアップしてから「誤収集を整理」で削除できる。既存の評価等は保護。
- 実際のNetflixログイン環境での収集は未検証。
